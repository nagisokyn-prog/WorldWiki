## 2.7. Обоснование выбора инструментов и платформы для разработки

Детальные сравнительные таблицы альтернативных СУБД, текстовых редакторов и архитектурных паттернов вынесены в [Приложение Б](../Приложение_Б_Сравнительный_анализ_стека_и_паттернов.md). Ниже приведено итоговое обоснование выбранного стека (сводка в таблице 2.2).

1. **СУБД — SurrealDB v3 (`kv-surrealkv`):** объединяет документную, реляционную и графовую (`TYPE RELATION`) модели, полнотекстовый поиск, триггеры (`EVENT`) и хранимые функции (`fn::*`) в одном встраиваемом ACID-движке `SurrealKV` без внешних сервисов (в отличие от PostgreSQL, Neo4j и MongoDB).
2. **Платформа — Tauri 2.x + Rust + WebAssembly (`wasm32`):** вместо упаковки отдельного Chromium (`Electron`, 500–1500 МБ ОЗУ) используется системный `WebView2`, что даёт бинарник ~54 МБ и потребление 350–400 МБ ОЗУ, а `#![no_std]`-ядра математики и парсеров на Rust компилируются как в нативный бэкенд, так и в WASM для фронтенда.
3. **Фронтенд и редактор — Vue 3 + TypeScript + Vite + Tiptap v3:** `Tiptap v3` (над `ProseMirror`) обеспечивает типизированный AST-документ, транзакционный Undo/Redo и нативное встраивание Vue-виджетов (`((Сущность))`) в текст. `Pinia` и `TanStack Query` разделяют локальное UI-состояние и кэш IPC-запросов, а CSS Custom Properties позволяют динамически переключать темы и профили нагрузки (`High`/`Medium`/`Low`).
4. **Архитектурные паттерны — Hexagonal Architecture + CQRS + FSD/MVVM:** бэкенд разделён на изолированные крейты (`domain`, `ports`, `application`, `infrastructure`, `tauri`), что исключает утечку SDK в домен и даёт 100% тестируемость на моках; внутри ядра применён CQRS для разделения мастер-текста `chapters.content` и индекса `text_blocks`. На фронтенде используется `FSD` и 4-компонентный `MVVM` (`*.vue` $\to$ `use*.ts` $\to$ `*.model.ts` + `stores`).

Таблица 2.2 — Выбранный технологический стек и архитектурные паттерны АС «WorldWiki»

| Слой системы | Выбранное решение | Ключевое обоснование |
|---|---|---|
| **Хранилище данных** | `SurrealDB v3` (`SurrealKV`) | Мультимодельность (Document + Graph + Fulltext), ACID, встраиваемость |
| **Нативная оболочка** | `Tauri 2.x` + `Rust` + `WASM` | Низкое потребление ресурсов (~54 МБ / 350–400 МБ ОЗУ), единые `#![no_std]`-ядра |
| **Клиентский стек** | `Vue 3`, `TypeScript`, `Vite`, `Pinia`, `TanStack Query` | Строгая типизация, Multi-Page окна, разделение UI- и серверного кэша |
| **Редактор текста** | `Tiptap v3` (`ProseMirror`) | Типизированный JSON AST, инлайн-виджеты `VueNodeViewRenderer` |
| **Архитектура** | `Hexagonal` + `CQRS` (Backend), `FSD` + `MVVM` (Frontend) | Изоляция домена, контроль границ (`Cerberus`), тестируемость без БД и DOM |
