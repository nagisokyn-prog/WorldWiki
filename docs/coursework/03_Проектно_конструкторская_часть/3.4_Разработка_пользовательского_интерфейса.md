## 3.4. Разработка интерфейса взаимодействия пользователя с системой

### 3.4.1. Многооконная структура приложения
Пользовательский интерфейс АС «WorldWiki» организован в виде независимых оконных процессов на базе единой кодовой базы (Multi-Page Architecture), что обеспечивает возможность распределения рабочих областей по нескольким мониторам:

1. **Главное рабочее окно (`app.html`):** основное рабочее пространство автора, включающее навигационное дерево проекта (`ExplorerTree`), двухуровневый редактор рукописи, карточки сущностей онтологии и временную шкалу.
2. **Окно плавающего ассистента (`ai.html`):** компактное открепляемое окно интеллектуального соавторства, обеспечивающее генерацию вариантов текста и проверку фактов мира без перекрытия основного документа.
3. **Окно системных настроек (`settings.html`):** интерфейс управления профилями пользователей, параметрами СУБД и ключами провайдеров.
4. **Окно студии стилей (`ui_editor.html`):** интерактивный конструктор тем оформления и NoCode-редактор динамических схем карточек сущностей.

---

### 3.4.2. Библиотека компонентов интерфейса и дизайн-токены
Для обеспечения визуального единообразия и ускорения разработки интерфейс строится на основе централизованной библиотеки `@worldwiki/components`, содержащей 28 базовых элементов управления (кнопки `AppButton`, модальные окна `AppDialog`, деревья `ExplorerTree`, селекторы `RangeSlider`, теги `TagsField` и др.).

Стилистическое оформление базируется на системе дизайн-токенов (CSS Custom Properties). Использование фиксированных значений цветов и радиусов скругления исключено в пользу семантических переменных:

```css
/* Пример семантических дизайн-токенов интерфейса */
--color-bg-primary: #0f1218;
--color-text-primary: #f1f5f9;
--glass-border: rgba(255, 255, 255, 0.08);
--glass-blur: blur(12px);
--border-radius-md: 8px;
--transition-normal: 0.2s cubic-bezier(0.4, 0, 0.2, 1);
```

### 3.4.3. Аппаратный бенчмаркинг и адаптивный рендеринг
Для обеспечения плавной отрисовки интерфейса (60 FPS) на вычислительных комплексах с различной графической мощностью реализован модуль аппаратного тестирования (`run_performance_benchmark`).

Система автоматически определяет уровень производительности и переключает графический профиль:
- **Профиль «High» (производительные GPU):** активен полный комплекс визуальных эффектов (эффект матового стекла Glassmorphism, фильтр `backdrop-filter: blur(16px)`, фоновое радиальное свечение, плавные микровзаимодействия и тени);
- **Профиль «Medium» (интегрированная графика):** сбалансированный режим (ограничение радиуса размытия до 8px, снижение прозрачности фонового свечения до 30%);
- **Профиль «Low» (энергосберегающий режим / слабые ПК):** полное отключение фильтров `backdrop-filter`, замена полупрозрачных слоев сплошными фонами, отключение декоративных анимаций для обеспечения максимальной отзывчивости.
