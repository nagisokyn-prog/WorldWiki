# 4. ПРОЕКТНО-ТЕХНОЛОГИЧЕСКАЯ ЧАСТЬ

## 4.1. Проектирование наполнения базы данных и структуры SurrealQL

### 4.1.1. Декларативная схема таблиц и триггеров
Информационная база данных разворачивается средствами декларативного языка SurrealQL. При проектировании схемы реализованы следующие ключевые конструкции:

```surrealql
-- Определение схемы проектов и каскадного удаления
DEFINE TABLE projects SCHEMAFULL;
DEFINE FIELD name ON TABLE projects TYPE string;
DEFINE FIELD genre ON TABLE projects TYPE string;
DEFINE FIELD created_at ON TABLE projects TYPE datetime DEFAULT time::now();

DEFINE EVENT cascade_project_delete ON TABLE projects WHEN $event = "DELETE" THEN {
    DELETE volumes WHERE project = $before.id;
    DELETE entities WHERE project = $before.id;
    DELETE calendars WHERE project = $before.id;
    DELETE plans WHERE project = $before.id;
};

-- Определение иерархии глав и ребер отношений
DEFINE TABLE chapters SCHEMAFULL;
DEFINE FIELD title ON TABLE chapters TYPE string;
DEFINE FIELD order_index ON TABLE chapters TYPE int;
DEFINE FIELD word_count ON TABLE chapters TYPE int DEFAULT 0;

-- Графовая таблица отношений между сущностями
DEFINE TABLE entity_rel SCHEMAFULL TYPE RELATION FROM entities TO entities;
DEFINE FIELD rel_type ON TABLE entity_rel TYPE string;
DEFINE FIELD strength ON TABLE entity_rel TYPE int ASSERT $value >= -100 AND $value <= 100;
DEFINE FIELD start_chapter ON TABLE entity_rel TYPE option<record<chapters>>;
DEFINE FIELD end_chapter ON TABLE entity_rel TYPE option<record<chapters>>;
DEFINE FIELD reason ON TABLE entity_rel TYPE option<string>;
```

---

### 4.1.2. Проектирование индексов быстродействия
Для оптимизации времени выполнения аналитических и поисковых запросов в схеме базы данных настроены специализированные индексы:
1. **Индекс временной шкалы:** B-Tree индекс по числовому полю `m_abs` таблицы `timeline_events` обеспечивает логарифмическую сложность выборки диапазона событий $O(\log N + K)$.
2. **Полнотекстовый индекс BM25:** индекс `idx_entity_search` по полям наименования и описания сущностей с учетом русской и английской лемматизации.
3. **Векторный индекс HNSW:** индекс по полю эмбеддинга таблицы `text_blocks` для быстрого поиска семантически близких блоков текста.

### 4.1.3. Тестовое наполнение и валидация миграций
Для верификации структуры базы данных разработан генератор синтетических данных, создающий тестовый литературный проект («Сага о Семи Королевствах»), включающий:
- 3 тома, 9 сюжетных арок и 27 глав;
- 60 сущностей базы знаний (персонажи, фракции, замки, реликвии);
- свыше 150 графовых ребер взаимоотношений (`entity_rel`) с различными весами силы и временными рамками;
- 2 авторские календарные системы («Имперское летоисчисление» и «Лунный календарь кочевников») с 40 синхронизированными событиями хронологии.

Тестирование подтвердило корректность работы каскадных триггеров и сохранение целостности базы данных при стрессовых модификациях схемы.
