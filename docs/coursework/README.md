## 🛠️ Сборка единого документа в Microsoft Word (DOCX) через Pandoc

Все математические формулы оформлены в совместимом стандарте LaTeX/Pandoc ($$ ... $$) и при конвертации автоматически преобразуются в **нативные редактируемые формулы Microsoft Word (OMML)**.

### Команда для сборки в один файл DOCX:

```powershell
pandoc `
  01_Техническое_задание.md `
  02_Исследовательская_часть/2.1_Введение_и_актуальность.md `
  02_Исследовательская_часть/2.2_Постановка_задачи_проектирования.md `
  02_Исследовательская_часть/2.3_Описание_предметной_области.md `
  02_Исследовательская_часть/2.4_Требования_к_системе.md `
  02_Исследовательская_часть/2.5_Анализ_аналогов.md `
  02_Исследовательская_часть/2.6_Перечень_задач_разработки.md `
  02_Исследовательская_часть/2.7_Обоснование_выбора_стека_и_СУБД.md `
  03_Проектно_конструкторская_часть/3.1_Описание_взаимодействия_пользователя.md `
  03_Проектно_конструкторская_часть/3.2_Логическая_схема_базы_данных.md `
  03_Проектно_конструкторская_часть/3.3_Разработка_архитектуры_приложения.md `
  03_Проектно_конструкторская_часть/3.4_Разработка_пользовательского_интерфейса.md `
  04_Проектно_технологическая_часть/4.1_Проектирование_наполнения_БД.md `
  04_Проектно_технологическая_часть/4.2_Реализация_математических_моделей.md `
  05_Заключение.md `
  06_Список_источников.md `
  -o WorldWiki_Пояснительная_Записка.docx `
  --toc `
  --number-sections
```
