# ПРИЛОЖЕНИЕ Г. СПЕЦИФИКАЦИЯ ЛОГИЧЕСКОЙ СТРУКТУРЫ БД И ПРЕЦЕДЕНТОВ ИСПОЛЬЗОВАНИЯ

В настоящем приложении приведены полная табличная спецификация основных реляционных и графовых таблиц базы данных АС «WorldWiki» (к разделу 3.2) и сводный перечень прецедентов использования системы (к разделу 3.3).

---

## Г.1. Спецификация логической структуры таблиц базы данных

Таблица Г.1 — Логическая структура основных таблиц и графовых рёбер SurrealDB

| Таблица / Граф | Ключевые поля и атрибуты | Связи и внешние ключи | Назначение |
|---|---|---|---|
| `projects` | `id`, `name`, `type`, `genres`, `cover_image`, `created_at` | Корневой узел | Метаданные литературного проекта |
| `volumes` | `id`, `title`, `project_id` | `project_id` $\rightarrow$ `projects.id` | Тома произведения |
| `chapters` | `id`, `title`, `content`, `sort_order`, `word_count`, `volume_id` | `volume_id` $\rightarrow$ `volumes.id` | Главы произведения (мастер-документ AST) |
| `text_blocks` | `id`, `chapter_id`, `block_type`, `order_index`, `content` | `chapter_id` $\rightarrow$ `chapters.id` | Семантические блоки текста главы |
| `story_arcs` | `id`, `project_id`, `title`, `status` | `project_id` $\rightarrow$ `projects.id` | Сквозные сюжетные арки (сторилайны) |
| `plot_promises` | `id`, `parent_id`, `block_ids`, `kind`, `time_nature`, `title`, `status`, `location_id`, `timeline_event_id` | `parent_id` $\rightarrow$ `plot_promises.id`, `timeline_event_id` $\rightarrow$ `timeline_events.id` | Рекурсивное дерево сцен и сюжетных обещаний |
| `todos` | `id`, `owner_id`, `arc_id`, `depends_on`, `text`, `status`, `is_done`, `sort_order` | `owner_id` $\rightarrow$ `volumes \| chapters \| story_arcs` | Задачи планировщика («Ткань сюжета») |
| `entity_schemas` | `id`, `project_id`, `type_key`, `type_name`, `fields_schema` | `project_id` $\rightarrow$ `projects.id` | Динамические мета-схемы типов сущностей |
| `entities` | `id`, `schema_id`, `name`, `description`, `tags`, `attributes` | `schema_id` $\rightarrow$ `entity_schemas.id` | Экземпляры объектов базы знаний |
| `entity_rel` *(Graph)* | `id`, `in` $\rightarrow$ `entities`, `out` $\rightarrow$ `entities`, `rel_type`, `strength`, `start_at`, `end_at` | `TYPE RELATION` между `entities` | Графовые ребра взаимоотношений |
| `appears_in` *(Graph)* | `id`, `in` $\rightarrow$ `entities`, `out` $\rightarrow$ `chapters \| text_blocks`, `source`, `count` | `TYPE RELATION` (`entities` $\rightarrow$ `chapters \| text_blocks`) | Граф упоминаний `((Сущность))` в тексте |
| `planets` | `id`, `project_id`, `name`, `ticks_per_day`, `axial_tilt_mdeg`, `moons` | `project_id` $\rightarrow$ `projects.id` | Астрофизические параметры планет |
| `calendars` | `id`, `planet_id`, `name`, `data`, `is_default`, `is_master` | `planet_id` $\rightarrow$ `planets.id` | Параметры авторских календарей |
| `timeline_events` | `id`, `project_id`, `title`, `description`, `m_abs`, `calendar_id` | `calendar_id` $\rightarrow$ `calendars.id`, `project_id` $\rightarrow$ `projects.id` | События хронологии мира ($M_{\text{abs}}$) |
| `participates_in` *(Graph)* | `id`, `in` $\rightarrow$ `entities`, `out` $\rightarrow$ `timeline_events`, `role` | `TYPE RELATION` (`entities` $\rightarrow$ `timeline_events`) | Участие сущностей в исторических событиях |
| `revealed_in` *(Graph)* | `id`, `in` $\rightarrow$ `timeline_events`, `out` $\rightarrow$ `chapters`, `pov_id`, `kind`, `block_id` | `TYPE RELATION` (`timeline_events` $\rightarrow$ `chapters`) | Нелинейное раскрытие событий в главах (режим читателя) |
| `participant_of` *(Graph)* | `id`, `in` $\rightarrow$ `entities`, `out` $\rightarrow$ `plot_promises`, `role` | `TYPE RELATION` (`entities` $\rightarrow$ `plot_promises`) | Участие сущностей в сценах и обещаниях |
| `advances_arc` *(Graph)* | `id`, `in` $\rightarrow$ `chapters \| plot_promises`, `out` $\rightarrow$ `story_arcs`, `phase` | `TYPE RELATION` $\rightarrow$ `story_arcs` | Продвижение фазы сюжетной арки |
| `occurs_at` *(Graph)* | `id`, `in` $\rightarrow$ `plot_promises`, `out` $\rightarrow$ `timeline_events`, `time_nature` | `TYPE RELATION` (`plot_promises` $\rightarrow$ `timeline_events`) | Временная фиксация сцены в таймлайне |
| `spans_blocks` *(Graph)* | `id`, `in` $\rightarrow$ `plot_promises`, `out` $\rightarrow$ `text_blocks`, `created_at` | `TYPE RELATION` (`plot_promises` $\rightarrow$ `text_blocks`) | Охват текстовых блоков сценой |
| `promise_milestones` *(Graph)* | `id`, `in` $\rightarrow$ `plot_promises`, `out` $\rightarrow$ `text_blocks`, `stage`, `quote` | `TYPE RELATION` (`plot_promises` $\rightarrow$ `text_blocks`) | Якоря жизненного цикла обещаний в тексте |
| `chapter_revisions` | `id`, `target_id`, `content`, `commit_msg`, `is_pinned`, `created_at` | `target_id` $\rightarrow$ `chapters.id` | Версионирование и снимки текста глав |

## Г.2. Спецификация прецедентов использования системы (Use Cases)

Таблица Г.2 — Сводный перечень прецедентов использования АС «WorldWiki»

| Код | Наименование сценария использования | Охватываемые компоненты системы |
| :---: |---|---|
| **UC-01** | Создание нового литературного проекта и настройка структуры произведения | Дерево рукописи, инициализация проекта |
| **UC-02** | Блочное семантическое редактирование текста с автоиндексацией AST | Текстовый процессор, семантические блоки |
| **UC-03** | Инлайн-линковка сущностей через синтаксис `((Имя))` с автодополнением | Текстовый процессор, база знаний |
| **UC-04** | Создание и NoCode-настройка динамической схемы атрибутов сущностей | Конструктор схем, метаданные сущностей |
| **UC-05** | Добавление сущности с заполнением структурированных атрибутов | База знаний, реестр сущностей |
| **UC-06** | Установление направленной темпоральной связи между сущностями | Граф связей, темпоральные интервалы |
| **UC-07** | Фиксация появления сущности в главе произведения (`appears_in`) | Граф связей, инспектор главы |
| **UC-08** | Параметризация вымышленной календарной системы и эпох | Подсистема хронологии, календари |
| **UC-09** | Добавление события хронологии и расчет абсолютной минуты ($M_{\text{abs}}$) | Подсистема хронологии, таймлайн |
| **UC-10** | Фиксация участия сущностей в историческом событии (`participates_in`) | Подсистема хронологии, граф связей |
| **UC-11** | Регистрация сюжетного обещания («чеховского ружья») из текста главы | Сюжетный контроль, редактор |
| **UC-12** | Отслеживание жизненного цикла драматургических обещаний | Сюжетный контроль, матрица ружей |
| **UC-13** | Создание многоуровневого дерева планов произведения | Подсистема планирования, композиция |
| **UC-14** | Запуск аппаратного бенчмаркинга и переключение адаптивного профиля | Подсистема настроек, графический адаптер |
