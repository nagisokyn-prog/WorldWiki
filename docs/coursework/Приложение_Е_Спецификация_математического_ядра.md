# ПРИЛОЖЕНИЕ Е. СПЕЦИФИКАЦИЯ МАТЕМАТИЧЕСКОГО ЯДРА (ЦЕПНЫЕ ДРОБИ И АЛГЕБРА АЛЛЕНА)

В настоящем приложении приведены справочные расчётные таблицы изолированного `#![no_std]`-модуля `worldwiki-calendar-core` к разделу 4.2: пример разложения тропического года в непрерывные цепные дроби и полная классификация 13 отношений интервальной алгебры Аллена.

---

## Е.1. Аппроксимация дробной части тропического года цепными дробями

Таблица Е.1 — Сходимость подходящих дробей и гармонических правил (глубина разложения до 10)

| Шаг | Подходящая дробь $p/q$ | Гармоническое правило | Эквивалентная длина года (сут) | Дрейф (сут / 10 000 лет) |
|---|---|---|---|---|
| 1 | $1/4$ | $+ \lfloor Y/4 \rfloor$ (юлианский) | $365{,}250000$ | $+78{,}1$ |
| 2 | $7/29$ | $7$ високосных за $29$ лет | $365{,}241379$ | $-8{,}1$ |
| 3 | $8/33$ | цикл Омара Хайяма | $365{,}242424$ | $+2{,}3$ |
| 4 | $31/128$ | $+ \lfloor Y/4 \rfloor - \lfloor Y/128 \rfloor$ | $365{,}242188$ | $-0{,}02$ |
| 5 | $97/400$ | $+ \lfloor Y/4 \rfloor - \lfloor Y/100 \rfloor + \lfloor Y/400 \rfloor$ | $365{,}242500$ | $+3{,}1$ |

## Е.2. Отношения интервальной алгебры Аллена

Таблица Е.2 — 13 взаимно-исключающих отношений алгебры Аллена над полуоткрытыми интервалами $[a_s, a_e)$ и $[b_s, b_e)$

| Группа отношений Аллена | Формальное условие над $[a_s, a_e)$ и $[b_s, b_e)$ | Семантика при аудите интервалов |
|---|---|---|
| `Before` / `After` | $a_e < b_s$ / $a_s > b_e$ | Интервалы строго не пересекаются (разделены во времени, коллизии нет) |
| `Meets` / `MetBy` | $a_e = b_s$ / $a_s = b_e$ | Стык полуоткрытых интервалов в граничной точке (пересечение пустое) |
| `Overlaps` / `OverlappedBy` | $a_s < b_s < a_e < b_e$ / $b_s < a_s < b_e < a_e$ | Частичное перекрытие интервалов (сигнал возможной билокации персонажа) |
| `Starts` / `StartedBy` | $a_s = b_s \land a_e < b_e$ / $a_s = b_s \land a_e > b_e$ | Совпадающее начало при разной длительности (одновременное присутствие на отрезке) |
| `During` / `Contains` | $a_s > b_s \land a_e < b_e$ / $a_s < b_s \land a_e > b_e$ | Строгое вложение одного интервала в другой (событие внутри времени жизни) |
| `Finishes` / `FinishedBy` | $a_s > b_s \land a_e = b_e$ / $a_s < b_s \land a_e = b_e$ | Совпадающее окончание при разном начале (пересечение на общем хвосте) |
| `Equals` | $a_s = b_s \land a_e = b_e$ | Полное совпадение двух временных отрезков |
