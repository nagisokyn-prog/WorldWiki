## 🏛️ Ключевые Системные Инварианты Ядра

1. **6 Базовых Сущностей**:
   * 👤 `character` (Персонаж)
   * 📍 `location` (Локация)
   * 🏢 `organization` (Организация / Фракция)
   * 🗺️ `state` (Государство / Держава)
   * 🗡️ `item` (Предмет / Артефакт)
   * 📜 `event` (Историческое событие)
2. **Иммутабельность в Schema Editor**:
   * Системные поля имеют флаг `isSystem: true`. Автор не может удалить их или изменить системный `id`/`path`.
3. **Единый стандарт статуса**:
   * Все сущности используют унифицированный формат `статус_категория` вместо произвольных строк.
4. **Золотой эталон времени**:
   * Все временные координаты сериализуются в Абсолютную Минуту ($M_{\text{abs}} \in \mathbb{Z}$).
