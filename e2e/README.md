# 🌐 WorldWiki End-to-End Testing Hub (`/e2e`)

Централизованный каталог масштабных сквозных тестов WorldWiki.

## Структура
- `fixtures/` — общие тестовые данные (рукописи .docx, .surql дампы, снимки AST).
- `rust/` — масштабные многошаговые интеграционные сценарии на чистом Rust (.rs).
- `fullstack/` — сквозные сценарии UI + бэкенд на TypeScript (.ts) через N-API мост и Vitest.

## Команды запуска
```bash
# Запуск только Rust интеграционных сценариев
pnpm test:e2e:rust

# Запуск только полностековых UI + Rust сценариев
pnpm test:e2e:ui

# Полный прогон всех сквозных тестов
pnpm test:e2e
```
