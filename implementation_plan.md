# Полная миграция редактора глав (Full Feature Parity)

Я полностью осознал свою ошибку: я перенёс только красивую обёртку (HTML) из прототипа `new_ui/index.html`, но выкинул сложнейшую доменную логику World-Wiki, которая годами писалась в Vanilla TS компонентах (`TimelineManager`, `ChapterEditorUI`, `WowilonPanel` и др.).


## Что было упущено и будет восстановлено во Vue:

### 1. Ядро редактора (ChapterEditorUI & UnifiedAutocomplete)
- Интеграция `UnifiedAutocomplete` для автодополнения сущностей прямо при наборе текста через `@`.
- Обработка `CTRL+Клик` по ссылкам на сущности внутри редактора для открытия `FloatingEntityEditor` (редактирование персонажа прямо поверх главы без закрытия текущего окна).
- Восстановление панели статуса (Word Count, Char Count, Время чтения).
- Инструменты тулбара: Вставка таблиц, картинок, ссылок, очистка форматирования, анализ текста, печать, полный экран.
- Система **Сносок (Footnotes)**: добавление, удаление, генерация markdown, отображение в отдельной панели.

### 2. Таймлайн и Участники (TimelineManager & TimelineUI)
- Автоматический парсинг участников: извлечение ссылок `[Имя](...?type=X&id=Y)` из текста (через регулярку) и авто-добавление их в список "Участники" на лету (`parseParticipantsFromText`).
- Мульти-ивентовый таймлайн: В одной главе может быть **несколько дат/событий**. Вместо одного `DateWheels` будет массив событий, у каждого свое поле выбора эпохи, года, месяца, дня и текста описания.
- Сохранение таймлайна в глобальный файл через `timelineService.saveChapterTimeline` вместе с сохранением самой главы.

### 3. Экспорт и WoWiLon AI (WowilonPanel & exportDialog)
- Полноценное окно **Экспорта глав** с выбором формата (txt, docx, pdf) и точечным выбором глав для выгрузки. Библиотеки (docx, pdf-lib, epubjs, latex, fb2) будут корректно импортированы.
- Возврат выдвигающейся панели AI-ассистента WoWiLon (с логикой чата и выбора типа запроса).

### 4. Интерфейсные механики
- **Изменение ширины правой панели** (перетаскивание ползунка `toolsPanelResizeHandle` с сохранением в localStorage).
- **Быстрые ссылки по Ctrl+Q**: восстановление подсказки и обработчика для быстрого прикрепления сущностей формата `[Имя]`.
