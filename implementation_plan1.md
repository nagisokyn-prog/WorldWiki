# Реализация структуры "Том-Арка-Глава" и Каркаса произведения

Этот документ описывает технический план интеграции древовидной иерархии глав (Тома -> Арки -> Главы) и системы планирования внутри редактора глав (вместо старого блока ручного добавления).

## ⚠️ Требует согласования (User Review Required)

> [!IMPORTANT]
> **Drag-and-Drop:** Планирую поддержку Drag-and-Drop для перетаскивания глав между арками/томами. Если сейчас лишнее — можно добавить позже, сначала реализую базовую структуру.

> [!WARNING]
> **Миграция БД:** Добавлю колонки `volume_id`, `arc_id`, `sort_order` и `planning_data` в таблицу `Chapters`. Старые главы по умолчанию попадут в "Корень" (без тома и арки).

> [!NOTE]
> **Каркас произведения:** Понял — это "план агента": структурированный список пунктов с индикатором ✅/🔲 напротив каждого. Аналог того, что пишут ИИ в `task.md`. Реализую именно так: добавление произвольных пунктов плана, вложенность (подпункты), переключение статуса кликом на кружок. Данные хранятся в JSON и привязаны к конкретному Тому, Арке или Главе.
