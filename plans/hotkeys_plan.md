# Hotkeys Plan — World-Wiki

## Украдено из VS Code (адаптировано)

| Комбо | Действие |
|-------|----------|
| `Ctrl+S` | Сохранить всё ✅ уже есть |
| `Ctrl+,` | Открыть настройки ✅ уже есть |
| `Ctrl+F` | Фокус на поиск в сайдбаре ✅ уже есть |
| `Ctrl+W` | Закрыть активную вкладку |
| `Ctrl+Tab` | Следующая вкладка |
| `Ctrl+Shift+Tab` | Предыдущая вкладка |
| `Ctrl+1..9` | Перейти на вкладку по номеру |
| `Ctrl+P` | Quick Open — быстрый поиск сущностей (как файлов) |
| `Ctrl+Shift+P` | Command Palette — список всех действий |
| `Ctrl+B` | Показать/скрыть сайдбар |
| `Ctrl+\`` | Показать/скрыть нижнюю панель (терминал) |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Отмена / Повтор (в редакторе) |
| `Ctrl+N` | Создать новую сущность текущего типа |
| `Escape` | Закрыть модальное окно / снять фокус |
| `F2` | Переименовать выбранный элемент в дереве |

## Специфично для World-Wiki

| Комбо | Действие |
|-------|----------|
| `Ctrl+Shift+S` | Сохранить только активную вкладку |
| `Ctrl+Shift+F` | Глобальный поиск по всем сущностям |
| `Alt+Left/Right` | Предыдущая/следующая страница в истории вкладок |
| `Ctrl+G` | Перейти к главе по номеру |
| `Ctrl+E` | Переключить вид (сущности ↔ главы) |
| `Ctrl+M` | Фокус в редактор / переключить markdown ↔ wysiwyg |
| `Ctrl+Shift+N` | Новая глава |
| `Ctrl+Shift+E` | Фокус на дерево (Explorer, как в VS Code) |
| `Alt+1..9` | Переключить секцию в редакторе сущности |
| `Ctrl+Shift+C` | Скопировать ID текущей сущности |
| `F5` | Принудительно перечитать данные с диска |

## Навигация без мыши

| Комбо | Действие |
|-------|----------|
| `↑/↓` в сайдбаре | Движение по списку сущностей |
| `Enter` в сайдбаре | Открыть выбранный элемент |
| `←/→` в дереве глав | Свернуть/развернуть узел |
| `Tab` / `Shift+Tab` | Переход между полями формы |
| `Ctrl+[` / `Ctrl+]` | Переключить вкладку секции влево/вправо |

## Вопросы для обсуждения

1. `Ctrl+P` — Quick Open: искать только текущий тип или все типы сразу?
2. `Ctrl+Shift+P` — Command Palette: нужен ли он или это лишнее?
3. `F5` — принудительный reload с диска или просто обновить список?
4. Нужен ли "режим Vim" для текстового редактора?
