# Полная реализация провайдеров и настроек ИИ (Roo Code UI Clone)

Цель: Сделать интерфейс настроек AI полностью функциональным, скопировав лучшие UX/UI решения из Roo Code. Юзер сможет создавать профили, гибко настраивать продвинутые параметры (Base URL, Temperature и др.) и использовать гибридный Combobox для моделей.

## Proposed Changes

### 1. Компонент AiSelect (Гибридный Combobox)

Мы переработаем `AiSelect.vue`:
- Клик по инпуту открывает полный список (без необходимости вводить текст для появления вариантов).
- Ввод текста фильтрует варианты.
- Если введено значение, отсутствующее в списке, оно не требует клика "Использовать X". При нажатии `Enter` или потере фокуса (blur) введённый текст автоматически становится `modelValue`.
- Это решает проблему пустого списка при отвале сети — можно просто вписать `claude-3-5-sonnet`.

- Упростить логику custom input: `searchQuery` автоматически биндится в значение модели, если не выбран элемент списка.

### 2. Интерфейс профилей ИИ (AiSettingsView.vue)

У нас уже есть готовая таблица `ai_profiles` в SurrealDB и сгенерированные CRUD команды. Мы полностью переработаем `AiSettingsView.vue`:
- **Выбор профиля:** Сверху добавим `<select>` или список вкладок для выбора активного профиля (например, "Для сложных задач", "Быстрый локальный код") с кнопкой "Создать новый профиль".
- **Интеграция с БД:** Использование команд `get_ai_profiles`, `create_ai_profile`, `update_ai_profile`, `delete_ai_profile`.

#### [MODIFY] [AiSettingsView.vue](file:///c:/Users/Kuzma/Desktop/WorldWiki/apps/spa/src/ts/features/ai/settings/AiSettingsView.vue)
- Добавление управления списком профилей (`AiProfile[]`).
- Добавление новых полей в форму настроек профиля:
  - **Base URL:** Опциональное поле (важно для OpenAI Compatible и локальных серверов).
  - **Custom Instructions:** Текстовое поле (textarea) для системного промпта уровня профиля.
  - **Advanced Settings (Accordion):**
    - `Temperature` (Range slider 0.0 - 2.0).
    - `Context Window` (Number input, важно для локалок).
    - `Max Tokens` (Number input).
    - `Thinking Budget` (Number input, для reasoning-моделей).
- Сохранение параметров профиля в поле `settings` (JSON) в БД.

### 3. Предзагрузка моделей (Caching/Hardcode)

Чтобы решить проблему "должно быть видно сразу":
- В `AiSettingsView.vue` мы сделаем кэширование списка моделей. При успешном вызове `fetch_ai_models` список моделей кэшируется в `localStorage`. В следующий раз он загружается моментально, а в фоне обновляется.
- Хардкод для OpenAI/Anthropic/Gemini будет возвращён на уровень фронтенда, чтобы он всегда был доступен мгновенно в кэше, даже без сети, как fallback.
