# План 4: UI/UX Реализация

## Цели и Задачи
- Интерфейс древовидных чатов.
- Интеграция Tiptap.
- Контекстный селектор (Multiselect Томов/Сущностей).

## 1. Левая панель: Иерархия чатов
- Клонируем или расширяем логику `ChapterTree.vue` для отображения списка чатов.
- Каждый узел дерева — это отдельный логический чат (`ai_chats`). Узлы можно перетаскивать (Drag&Drop), меняя `parent_chat_id`.
- Добавляем поле поиска с фильтрацией по названиям и тегам.
- Сверху — акцентная кнопка "Новый чат".

## 2. Область чата и рендер сообщений
- **Tiptap**: Вместо обычного `<div v-html="..."/>`, рендерим сообщения через Tiptap (в режиме Read-Only для истории и Write-Mode для ввода пользователя). Поддерживаем Markdown и отображение формул (LaTeX).
- **Стрелочки навигации `< >`**: Если у сообщения есть "сиблинги" (сообщения от того же родителя — например, если ИИ ответил, а потом пользователь отредактировал этот ответ), отображаем стрелочки `1 / 3 < >`, как в ChatGPT, чтобы можно было переключаться между версиями.
- **Ветвление (Forking)**: Возле каждого сообщения — кнопка `[Разветвить]`. При нажатии создаётся новый `chat`, который ссылается на это сообщение как на корень новой ветки, и пользователя перекидывает в неё.

## 3. Контекст-Селектор (Кнопка `+`)
- Кнопка `+` в поле ввода открывает многоуровневое меню:
  - Уровень 1: Тома | Арки | Главы | Сущности
  - Уровень 2: Если Тома -> [Список Томов]. Если Сущности -> [Список Типов (Персонаж, Локация)].
  - Уровень 3: Если Типы -> [Список Сущностей (Гендальф, Фродо)].
- Реализуется через Vue-компонент со стеком навигации (как меню в iOS). Добавляет красивые теги выбранного контекста прямо над полем ввода.
- При отправке сообщения, `ui_editor` отправляет массив `attachments` в Tauri, который уже подтягивает данные из SurrealDB и скармливает их в системный промпт.

## 4. Панель Настроек и Auto-Approval
- **Карточки с Tool Calls**: Во время работы инструмента в потоке чата появляется специальный блок (например, шестерёнка крутится "Ищу сущность...").
- Если действие требует аппрува, кнопка `[Разрешить]`, `[Отклонить]` и чекбокс `[Больше не спрашивать для создания "character"]` (обновляет Auto-Approval Allowlist).
- **Переключатели Режимов**: `[Собеседник] [Редактор] [Аналитик]` над чатом. При переключении меняется набор доступных инструментов и системный промпт (может потребовать сброса памяти ИИ).
