# План 5: Казуальный Центр Локальных Моделей (Model Hub)

## Цели и Задачи
- Сделать скачивание, настройку и запуск локальных нейросетей доступным для обычного писателя.
- Автоматизировать выбор квантования (Q4/Q8) на основе "железа" пользователя.
- Интегрировать Hugging Face API для динамического каталога моделей.

## 1. Встроенный каталог моделей (Hugging Face API)
Вместо жёстко зашитых ссылок, мы подключаемся к публичному API Hugging Face (`https://huggingface.co/api/models`). 

Внутри магазина ИИ-помощников мы делаем две вкладки:

### Вкладка А: "Рекомендованные" (Для казуалов)
Здесь мы выводим 3-4 вручную отобранные модели, которые 100% идеально пишут на русском языке и подходят для творческих задач (например, Qwen 2.5, Saiga). Мы переименовываем их для людей: не `TheBloke/Llama-2-13B-chat-GGUF`, а `Универсальный Писатель (13B)`.

### Вкладка Б: "Поиск по Hugging Face" (Для энтузиастов)
Мы отправляем GET-запрос к API Hugging Face с жёсткими фильтрами:
- `pipeline_tag=text-generation`
- `library=gguf` (или тег `llama.cpp`)
- `license=mit` (и другие коммерчески безопасные лицензии: apache-2.0, openrail)
- Сортировка по количеству скачиваний или лайков.

Пользователь видит живой, постоянно обновляющийся список прямо из WorldWiki. Он может вбить в поиск "Russian" или "RP" и получить модели.

## 2. Умное скачивание правильного файла
В репозиториях на Hugging Face (например, у `bartowski`) обычно лежат десятки файлов: от `Q2_K` до `Q8_0`. Казуал не знает, что это.
При нажатии кнопки **[Скачать]** на любой модели, бэкенд WorldWiki:
1. Запрашивает через API список файлов в этом репозитории.
2. Проверяет объём оперативной и видеопамяти пользователя.
3. Автоматически выбирает идеальный баланс качества и скорости (обычно `Q4_K_M` или `Q5_K_M`), который влезет в RAM/VRAM пользователя.
4. Качает именно этот файл и кладёт в папку `AppData/Local/WorldWiki/models`.

## 3. Скрытие страшных настроек
Писателю не нужно видеть настройки вроде `Context Size`, `Temperature`, `GPU Offload Layers`.
- По умолчанию эти настройки **скрыты**. 
- Приложение само выставляет оптимальные параметры: выгружает максимум слоёв на видеокарту и ставит температуру для креатива.
- Для энтузиастов есть тумблер **[ Показать настройки для гиков ]**. Там они могут выкрутить температуру или изменить размер контекста.

## 4. Рабочий процесс пользователя
1. Пользователь нажимает на иконку "Локальный ИИ".
2. Во вкладке "Рекомендованные" жмёт "Скачать" у подходящей под его ПК модели.
3. Либо идёт в "Поиск", находит свежую модель от комьюнити и жмёт "Скачать".
4. WorldWiki сам определяет железо, скачивает правильный `.gguf` файл.
5. Появляется кнопка **[ Начать чат ]**. Сервер поднимается в фоне автоматически.
